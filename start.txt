rem Maven/Spring Boot build:
mvn clean package

rem Bars are read from a CSV file - no database, no env vars needed anymore.
rem CSV format: <ignored>;<dateTime dd.MM.yyyy HH:mm:ss>;<open>;<high>;<low>;<close>;<volume>
rem (first line is treated as a header and skipped)

rem Run via the packaged jar:
java -jar target/stock-analyzer.jar name_bmw time_30 csv_bmw_1min.csv ta_macd_12_26_9

rem or via the Maven plugin during development:
mvn spring-boot:run -Dspring-boot.run.arguments="name_bmw time_30 csv_bmw_1min.csv ta_macd_12_26_9"
